# Add a reference

Assign a neutral visual ID such as growth-editorial, not a source brand or builder name. Inspect the supplied analysis and images. Preserve source attribution, access conditions and uncertainty in the maintainer provenance ledger outside the installed skill; a neutral ID is not a license or a substitute for legally required attribution.

Create a dossier describing fit, composition grammar, token relationships, section anatomy, states, transitions, responsive transformations and verification status. Identify what is measured, inferred or unverified. Keep visual relationships, not just a list of hex values. Record interactions as trigger → state change → timing → mobile/reduced-motion fallback.

Use independently written recipes. Do not bundle scraped source, branded copy, logos, remote image URLs or unlicensed assets. If screenshots or code are distributable, record the permission and package them with appropriate notices. Otherwise keep textual abstraction and ask for permission-appropriate material only when necessary for the requested output.

Add a catalogue row with the fit, distinguishing grammar and dossier link. Extract a common interaction recipe only after it has a concrete reusable purpose. Reference-specific numbers remain in the dossier, not global skill rules.
